# SpecialRatizens（特殊鼠鼠）v0.1.5

## 更新内容

- **独立插件首发**：特殊鼠鼠系统从整合版迁移为独立插件 `SpecialRatizens`，并完成大幅精简与修复。
- **修复同一存档重复招募**：已招募状态、保底计数（`pdr_C`）与名字占用随存档 `D_Data.ModsData` 持久化，读档时序提前重建会话，彻底消除读档后同一鼠鼠再次出现的竞态。
- **死亡后再招募策略**：遗体仍在死亡名单期间该鼠鼠不会重新出现；遗体被移除后重新进入候选池，保底计数延续存档值。
- **修复读档后特性名称/描述不显示**：游戏读档会清空 ScriptableObject 特性库的显示字段，现在每次会话从不可变定义快照重建特性对象，详情面板恢复显示，存量存档读档时自动愈合。
- **功能精简**：只保留特殊鼠鼠本体与 24 个特性效果的完整链路（生成/招募/命名/三维金币/专属皮肤/状态图标），移除整合版中所有无关功能（设置窗口、共享仓库、乌托邦、AI、无人机/机器人翻倍等）。
- **数据位置收敛**：运行数据只存于存档 `D_Data.ModsData` 与 BepInEx 配置文件（`General.Enabled` 总开关、`General.CustomNames` 更多名称开关），不再产生任何额外存档文件。
- **「更多名称」恢复并接活**：移民与随机市民从 `Data/Names.json` 生成中文姓名并避开已占用名字（迁移后一直未生效，本次补齐 3 个 Harmony 补丁）。
- **日志规范化**：统一 `ModLog` 出口（对齐 YunQing.All 风格），关键事件 Info、高频细节 Debug，默认日志干净可排查。
- **修复打包缺失资源**：发布包现在包含 `Data/` 下的全部 JSON 配置与 24 张特性图标（此前打包脚本只收集顶层文件导致缺失）。

## 安装方式

1. 下载 `SpecialRatizens-v0.1.5.zip`
2. 解压到 Ratopia 游戏根目录
3. 确认文件位于 `BepInEx/plugins/SpecialRatizens/`，且其下包含 `Data` 目录（`CustomSpecialUnit.json`、`CustomCharInfo.json`、`Names.json`、`Icon/`）

> 缺少 `Data` 目录会导致 12 名特殊鼠鼠与 24 个特性无法加载（v0.1.5 之前的包即存在此问题，请务必使用本版本）。
