# 多用途研究点 v0.1.11

Ratopia BepInEx 5 Mono Mod。研究点完成原版科技研究后仍可在研究界面中作为额外资源使用：向国家出售、短期提高普通鼠民工作效率、永久提升女王力量/智慧/敏捷。

## 功能

- 打开原版研究界面后，分类选择界面会显示独立的“多用途研究点”卡片；即使尚未解锁工程、电力和宗教研究，也不会与“基本”卡片重叠；节点、字体、卡片和按钮继续复用游戏内资源。
- 进入多用途研究点后，原版研究图与原版右侧详情会整块隐藏；右侧独立提示面板立即显示选择说明，选择项目后显示对应效果、消耗和“执行”按钮。
- 多用途界面会隐藏原版顶部研究栏目以及右侧克隆详情中的“查看详情”热键提示，退出后按进入前状态恢复。
- 四个功能项目与国家项目使用独立布局；国家每行最多 6 个，最后一行自动居中，完整国家列表不会越出研究区域。
- 自定义研究图和右侧详情使用独立 UI 层，切换到其他界面再返回时不会与原版节点或“仓库”详情争用同一对象。
- 不再停用或拦截原版 `ResearchUI.Update`，ESC 返回、左右分类切换和原版关闭流程保持可用。
- 学术出口只显示已探索且非敌对国家。每次默认消耗 50 研究点，收入基数 8000，关系 `+2`，购买国繁荣 `+5`；收入倍率按关系和购买国繁荣度计算并限制在 `0.90–1.20`。
- 全民动员默认消耗 50 研究点，为全体普通鼠民提供 `+10%` 工作效率，持续 3 个游戏日；重复购买刷新时间而不叠加。
- 女王进修每次固定消耗 50 研究点，每次力量、智慧或敏捷 `+1`，重复进修不再增加成本。

## 配置

配置文件位于 `BepInEx/config/cn.ratopia.multipurposeresearch.cfg`，启动时读取，修改后重启生效。成本、持续时间、效率、出口收入、外交奖励、倍率上下限和女王增长/递增成本均可配置；女王递增成本设为 `0` 时保持固定成本。`v0.1.11` 会把仍等于旧版默认值的成本自动迁移为 50。无效值（负数、NaN、Infinity、溢出或最低倍率大于最高倍率）回退默认值并写入日志。

## 安装

1. 完全退出 Ratopia。
2. 确认已安装 BepInEx 5.4.23.5。
3. 解压发布包到 Ratopia 根目录，文件应位于 `BepInEx/plugins/多用途研究点/多用途研究点.dll`。
4. 启动游戏并在 `BepInEx/LogOutput.log` 确认插件加载和补丁成功。

本工程默认只构建、不自动安装，也不会修改游戏 DLL。

## 存档与卸载

状态写入原版预留的 `D_Data.ModsData`，键为 `cn.ratopia.multipurposeresearch.state`。限时效率保存实际百分比和到期日；女王保存累计实际加成和购买次数。移除 Mod 后原版忽略该键，女王 Mod 加成不再生效。首次验收请使用存档副本，并至少完成两轮保存、完全退出和读档。
